🎯 FLUXO DE USO BÁSICO
═══════════════════════════════════════════════════════════════════════════

1. Registrar conta
   POST /auth/register
   
2. Fazer login
   POST /auth/login → recebe token JWT
   
3. Criar produtos (como vendedor)
   POST /products com token
   
4. Listar produtos
   GET /products (sem autenticação)
   
5. Fazer pedido (como comprador)
   POST /orders com token
   
6. Acompanhar pedido
   GET /orders com token

🔌 ENDPOINTS PRINCIPAIS
═══════════════════════════════════════════════════════════════════════════

AUTENTICAÇÃO
  POST /auth/register        - Criar conta
  POST /auth/login          - Fazer login

USUÁRIOS
  GET /users/me             - Meu perfil
  GET /users/{id}           - Ver usuário

PRODUTOS
  POST /products            - Criar
  GET /products             - Listar
  GET /products/{id}        - Ver
  GET /products/my-products - Meus
  PUT /products/{id}        - Atualizar
  DELETE /products/{id}     - Deletar

PEDIDOS
  POST /orders              - Criar
  GET /orders               - Listar meus
  GET /orders/{id}          - Ver
  PATCH /orders/{id}/status - Mudar status
  POST /orders/{id}/cancel  - Cancelar

SAÚDE
  GET /health               - Health check
  GET /docs                 - Documentação Swagger
  GET /redoc                - Documentação ReDoc

💡 EXEMPLOS RÁPIDOS
═══════════════════════════════════════════════════════════════════════════

REGISTRAR:
  curl -X POST http://localhost/auth/register \
    -H "Content-Type: application/json" \
    -d '{
      "email":"user@example.com",
      "username":"usuario",
      "password":"Senha123!"
    }'

LOGIN:
  curl -X POST http://localhost/auth/login \
    -d "username=usuario&password=Senha123!"

CRIAR PRODUTO:
  curl -X POST http://localhost/products \
    -H "Authorization: Bearer TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "name":"iPhone 15",
      "price":3999,
      "stock":10
    }'
